Case study

From course project to product

Roadrunner Roasts started as a full-semester team project in a UTSA software engineering course: a PHP/MySQL ordering site with Bootstrap 3. This redesign keeps its core idea (a campus coffee menu, a cart and checkout) and rebuilds the experience the way I'd ship it today.

Original team project

  • Separate PHP pages, full reload on every click
  • Fixed items with no way to customize a drink
  • Shipping-address form for a coffee order
  • Mixed clip-art and low-resolution photos
  • Sidebar menu that hides navigation on phones
Open the original

2026 redesign

  • Single-page order flow with a slide-out cart
  • Size, milk, extra shot and sweetness with live pricing
  • Order-ahead pickup times instead of shipping
  • Consistent hand-drawn SVG illustrations
  • Mobile-first, keyboard-friendly dialogs, reduced-motion support
  • Promo codes, Texas sales tax, rewards stars and live order tracking

HTML · CSS · JavaScript (ES modules) · no framework, no build step
